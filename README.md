## Selected Projects

### [Conversational Analytics Workbench](https://github.com/buthaphan/conversational-analytics-workbench)

Ask business questions in plain English and get answers you can check, using Google's public TheLook e-commerce dataset. Claude picks one approved analysis and fills in its settings, and the API checks that choice. BigQuery and PostgreSQL calculate every number, so the model never writes SQL or makes up figures. Each answer comes with a chart and the table of exact values behind it.

**Focus:** React, TypeScript, NestJS, Prisma, PostgreSQL, BigQuery, Claude API (structured outputs), ECharts, Vitest, Docker and GitHub Actions. Built test-first with a spec-driven agentic workflow. Includes a 61-case model evaluation (98.4%) and an exact-match check of the queries against known answers.

### [AI Vehicle Recognition](https://github.com/buthaphan/turners-ai-vehicle-recognition-app)

Full-stack application integrating AI-powered vehicle recognition with a React/TypeScript frontend and Node.js backend.

**Focus:** React, TypeScript, Node.js, Express, Azure AI, Custom Vision, API integration and testing.

### [AI Insurance Recommendation Assistant](https://github.com/buthaphan/ai-insurance-recommendation-assistant)

AI-powered full-stack application combining generative AI with deterministic business rules to provide policy recommendations.

**Focus:** React, TypeScript, Node.js, Express, AI provider abstraction, rules engines, Docker, Azure and CI/CD.

### [TradeMe Auction Search API](https://github.com/buthaphan/trademe-auction-search-api)

Backend application using MongoDB and Mongoose for auction data, with keyword search and experimental semantic search using Azure OpenAI embeddings.

**Focus:** Node.js, Express, MongoDB, Mongoose, Jest, Supertest, data seeding and semantic search.
